# Slider icons

One image per target slider, named after the slider. A missing image shows an
empty box.

## The 31 asymmetry icons

They show the face pushed to one end of the slider, plus the region the target
displaces, painted from the target file itself.

The deformation is **exaggerated**, ×1 to ×4 per slider: at real amplitude most
of these move one or two millimetres, invisible at icon size. So the icon gives
the place and the direction, not the magnitude. The amount is the smallest one
whose effect clears the rendering noise, and it stays below the point where the
mesh starts to look deformed rather than asymmetric.

They are framed from the front and centred on the body axis, close-ups
included: an asymmetry is read against the symmetry it breaks, so both sides
stay in frame.

256×256, where the older icons are 128×64.

Rendered by <https://github.com/ashledombos/makehuman-vignettes-tools>.
